# Nvidia_RTX_Nodes_ComfyUI

A collection of ComfyUI nodes powered by the NVIDIA RTX Video Effects SDK. Only works on Nvidia RTX GPUs.

## Nodes

- **RTX Video Super Resolution** — Upscale images and videos from compressed/low-quality sources.
- **RTX High Bitrate Upscale** — Upscale clean, high-bitrate source material with quality preservation.
- **RTX Denoise** — Remove noise from images with configurable strength (Low/Medium/High/Ultra).
- **RTX Deblur** — Remove motion blur from images with configurable strength (Low/Medium/High/Ultra).

## Installation

Clone this repo into your ComfyUI `custom_nodes` folder:

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/rekuenkdr/Nvidia_RTX_Nodes_ComfyUI.git
```
